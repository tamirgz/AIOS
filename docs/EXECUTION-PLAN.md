## The Life OS (L1–L3) — what it is

The centrepiece from here. AIOS becomes the place you *run* your day/week/projects/ideas via one **attention loop**: living projects (world model) → chief-of-staff agents that **observe** your real activity → a single typed **attention-item** atom → three views (**"Needs you" queue**, **project cockpit**, **Plan-my-day**), governed by a **trust gradient**. It maintains itself instead of asking to be fed. Full design in **ONE-STOP-PLAN §3**; the old "W3 delegation UX" folds into L1's spine.

## Standing principles

- **The heartbeat runs free.** Every periodic/scheduled agent uses a **free local model** — `qwen3:8b` by default (tested 2026-07-23: reliable tool-calls, ~6s), `gemma4:31b-it-qat` for the weekly synthesis. Claude is only for one-off, on-demand judgment. The metered-key guard already forbids anything paid.
- **Observe, don't ask to be fed.** Derive health, next-actions, follow-ups and loose ends from calendar/email/git/notes and the *absence* of activity — ask only for decisions.
- **Memory is load-bearing**: blocks stay terse (budgets enforced); everything durable goes to archival via `memory.remember`; agents recall before re-deciding; the Sunday consolidation agent keeps both fresh. Nothing important lives only in a chat transcript.
- **Volume, summarization & the heartbeat → local Ollama; one-off judgment & action → Claude Max.**
- **Merge is manual, always.** Agent work stays on its branch until you click.
- **Every phase independently useful; every exit test runs in the real system.**
- Operational: `aios` to start (prod default); migrate ⇒ restart web+worker; never rebuild under a running server; backups nightly at 03:30.
